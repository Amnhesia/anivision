## Qué ofrece

| | |
|---|---|
| **Sub y latino** | Cambia de idioma en cada episodio cuando hay doblaje disponible. |
| **Sin internet** | Descarga episodios o temporadas completas, en la calidad que elijas. |
| **Avisos de estrenos** | Activa la campanita de un anime y recibe una notificación con cada episodio nuevo. |
| **Sigue donde lo dejaste** | Tu progreso se guarda en tu cuenta y se sincroniza entre la app y la web. |
| **Reproductor completo** | Velocidad, repetir, segundo plano, ventana flotante, capturas, bloqueo de pantalla y gestos de brillo y volumen. |
| **Enviar a la TV** | Mira en tu televisor con Chromecast. |
| **Listas y comunidad** | Favoritos, viendo, terminados, valoraciones y comentarios por episodio. |
| **Temas de color** | Más de 20 temas, con Grafito por defecto. |

## Instalar

1. Descarga el archivo **.apk** desde [anivision.lat/descargar](https://anivision.lat/descargar) o desde la [última versión](https://github.com/Amnhesia/anivision/releases/latest).
2. Ábrelo en tu teléfono. Si Android lo pide, permite **instalar apps desconocidas** para tu navegador o administrador de archivos.
3. Si aparece un aviso de Google Play Protect, toca **Más detalles > Instalar de todos modos**. La app no se publica en Play Store, por eso Android no la reconoce.

> Descarga ANIVISION solo desde este repositorio o desde [anivision.lat](https://anivision.lat). Las copias modificadas que circulan en otros sitios pueden traer software malicioso y la app no funciona con ellas.

## Actualizaciones

La app avisa sola cuando hay una versión nueva y se actualiza sin salir de ella. Las notas de cada versión están en [Releases](https://github.com/Amnhesia/anivision/releases).

Solo se mantiene disponible la versión vigente: las anteriores se retiran al publicar una nueva.

## Requisitos

- Android 7.0 o superior.
- Conexión a internet para ver en línea (las descargas funcionan sin conexión).
- Unos 80 MB de espacio para la app, más lo que ocupen tus descargas.
